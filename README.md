# 単語手帖

『改訂版 必携英単語 LEAP』の番号で範囲を決め、通学中に前日の苦手語を復習できる日本語の静的Webアプリ。ログインやAPIキーは不要です。[アプリを開く](https://megaminxkr.github.io/leap_robot/)

## 初めて使う

1. ホームの「単語を取り込む」から[改訂版の単語一覧](https://ukaru-eigo.com/leap-modified-list/)を開きます。
2. 表の No・単語・意味の3列で、必要な行を選択してコピーします。表全体も、表計算ソフトからのタブ区切りも使えます。
3. 貼り付け欄に貼り付け、先頭5件、新規・更新・登録済みの件数を確認して「確認して保存」を押します。
4. 例として開始番号を301、終了番号を400にして「範囲を適用」を押します。ホームで「復習を始める」を押すと、期限の来た語、次に新出語が出ます。「全範囲」で以前の記録を引き継いで受験勉強に移れます。

番号は1〜2300。品詞、括弧、丸数字、セル内改行を含む意味を1つの欄に保持します。エラーのある貼り付けは一括で保存を止め、行・番号・理由を表示します。同じ番号と見出し語の再取り込みでは訳だけ更新できます。登録済み番号に別の見出し語が入っている場合は修正が必要です。

公開リポジトリには独自サンプル16語とオリジナル問題を収録しています。サンプルの番号は体験用です。個人用の表・履歴とは別の単語帳に保存します。収録語一覧の公開再配布条件を確認できていないため、元表は各自が取り込む方式です。

## 出題と復習

- **今日の復習**　指定範囲・選んだ方向の期限到来語から、苦手語、古い期限の順で出し、空き枠に新出語を加えます。初期設定は1回10問、新出は最大5語。設定で変更できます。
- **カード**　英→日と日→英を選べます。答えを開いた後に自己評価します。Spaceで開き、1・2・3で「思い出せた・あいまい・思い出せなかった」を記録できます。
- **練習**　指定範囲または単語帳の検索結果から重複なしに抽選します。四択は対象語義と誤答3件を編集済みの組合せで作ります。入力と空所補充は独自の語義・頭文字・文字数で対象を示し、大文字小文字と前後の空白を吸収します。空所補充は文が要求する語形で採点します。例えば lend の過去形を求める問題は lent が正解です。
- **対応語数**　取り込み語に編集済みの見出し語と対応語義の目印があれば、自動採点問題を利用できます。四択の候補や入力問題が足りない語はカードで学習します。空所補充は「練習の設定」に表示した対応語だけから選びます。
- **範囲テスト**　各問では提出のみ行い、全問終了後に採点・見直し・解き直しができます。自動採点の材料がないカードは解答を記入し、全問終了後に正答と比べて自己採点します。
- **復習間隔**　初期値は1・3・7・14・30日。期限日にその日の初回で自力正解すると段階が進み、最終段階では最後の間隔を繰り返します。誤答・あいまい・ヒント正解は翌日に戻します。通常練習では最大2問挟んで一度だけ再出題します。残りが少ない場合は末尾で解き直します。
- **学習記録**　端末の暦日を使います。同日の正解で段階を二重に上げず、同日中の解き直しも、翌日の復習予定を維持します。方向別に、初回の自力正解、以前に学んだ語を別の日の初回で自力正解した回数、同日の解き直し成功を集計します。範囲別に苦手語と次回の予定を表示します。

自分で思い出す機会を繰り返す設計は、外国語語彙の遅延再生を扱った Karpicke & Roediger（2008）を参考にしました。[Science, DOI 10.1126/science.1152408](https://doi.org/10.1126/science.1152408)

復習を複数の日に分ける設計は、第二言語学習での分散練習を検討した Kim & Webb（2022）のメタ分析を参考にしました。問題数・間隔はいずれも調整可能なアプリの初期設定です。[Language Learning, DOI 10.1111/lang.12479](https://doi.org/10.1111/lang.12479)

## 保存と端末の移行

このサイトのIndexedDBに両方の単語帳、回答、復習設定、進行中のセッションを保存します。回答と進捗を同一トランザクションで確定します。複数タブで更新が衝突した場合は最新の状態を読み直します。設定からJSONバックアップを書き出し、別端末の同じ画面で復元できます。ファイル全体を検証した後、件数を確認して復元を確定します。進行中の問題はバックアップの対象外です。

## 開発とテスト

Node.js 24 と npm を使用します。

~~~sh
npm install
npm run dev
~~~

開発用URLは起動時に表示されます。以下で型チェック、固定日時・固定乱数のロジックテスト、本番ビルド、Chromium・WebKitのブラウザテストを実行します。

~~~sh
npm run typecheck
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run e2e
npm run preview
~~~

プレビューは `/leap_robot/` から開きます。画面遷移はハッシュを使用します。`src/bank.ts` に語義の照合条件・独自例文・許容語形・四択の誤答候補があり、`tests/` に境界値と学習動線のテストがあります。

## GitHub Pages の公開

1. `main` にソースを保存します。「Verify study app」が型チェック、テスト、Viteビルドとブラウザ検証を実行します。
2. 検証が通ると、生成されたHTML・CSS・JavaScript・アイコン・`.nojekyll` を `gh-pages` ブランチのルートに反映します。
3. リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch → gh-pages → /(root) → Save** を選びます。
4. 以後の更新は同じ検証を経て公開ブランチに届きます。ワークフローは公開済みのPagesに再ビルドを要求します。`main` には開発用のTypeScriptがあります。

公開URLは [megaminxkr.github.io/leap_robot](https://megaminxkr.github.io/leap_robot/) です。
